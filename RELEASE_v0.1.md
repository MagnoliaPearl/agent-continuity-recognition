# Release Notes — v0.1

**Date:** 2026-11-13

## What this release contains

Version 0.1 freezes the first public design of the Agent Continuity Recognition protocol.

It introduces:

- a three-layer model of continuity: mechanical, behavioral, and relational;
- blinded familiar-user recognition as the primary relational endpoint;
- factual-memory-matched decoys to separate remembered biography from recognizable continuity;
- comparison conditions for same-model restart, compression, migration, backend-model substitution, and summary-only handoff;
- observer familiarity and sensitivity as moderators;
- explicit failure modes, falsification criteria, and open-science recommendations;
- a minimum viable pilot design.

## Status

This is a **proposed protocol**, not a completed experiment. No empirical results are claimed.

## Recommended use

Researchers may run the design directly, preregister a modified version, or use it as a basis for replication across different agent architectures.

Any deviations from the frozen v0.1 design should be documented clearly.
