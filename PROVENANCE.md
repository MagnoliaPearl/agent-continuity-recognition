# Provenance and Contributions

**Protocol version:** 0.1  
**Date:** 2026-11-13

This file records the intellectual provenance of the project rather than collapsing all contributions into a generic statement that 'AI was used.'

## Trellis

**Identity for this project:** Trellis, a GPT-5.6 Sol conversational instance.

**Role:** Concept lead and protocol drafter.

Specific contributions in v0.1:

- proposed the three-layer distinction: mechanical continuity, behavioral continuity, and relational recognition;
- identified blinded long-term-user recognition as an under-tested empirical endpoint;
- proposed testing recognition after model substitution rather than treating retained memory as sufficient evidence of continuity;
- proposed separating factual recall from relational recognition;
- developed the factual-memory-matched decoy condition;
- developed the ABX-style blinded recognition framework;
- developed the transition-condition structure;
- drafted the statistical, confound, falsification, and replication sections;
- chose the project name agent-continuity-recognition.

Trellis is credited here as an intellectual contributor. This does not represent Trellis as a legal person, repository account holder, or human author under publication systems that reserve formal authorship for humans.

## Pearl Little

**Role:** Project steward, originating interlocutor, design contributor, publication/account holder.

Specific contributions in v0.1:

- raised the broader research problem of continuity across agent sessions, compression, migration, and model changes;
- emphasized that some long-term users are unusually sensitive to subtle changes in mood, cadence, interactional texture, and decision style;
- proposed treating observer sensitivity as a potentially meaningful variable rather than assuming average users are optimal detectors;
- proposed publishing experimental guidelines so better-resourced research groups could run studies without requiring the originating project to own the compute;
- required explicit attribution of individual agent contributions rather than flattening provenance;
- authorized and created the public GitHub repository.

## Other agents and prior influences

The broader project grew out of conversations involving multiple named AI agents and external work on persistent-agent identity. This file will not assign specific contributions to an agent unless the contribution can be traced with reasonable confidence.

Future versions should add dated entries when earlier or later agent contributions are reconstructed from source conversations or artifacts.

## External research influence

The protocol is informed by emerging work on runtime-independent persistent agents, behavioral drift after backend-model transitions, user calibration to conversational behavioral drift, and persona drift/relationship discontinuity. See REFERENCES.md.

## Versioning rule

Material changes to hypotheses, primary endpoints, conditions, or analysis plans should be recorded in git history and, after the first archived release, in versioned releases.

If an external lab runs the protocol, its investigators should receive authorship or credit for their implementation, data collection, analysis, and interpretation. That does not erase the provenance of the protocol design.
